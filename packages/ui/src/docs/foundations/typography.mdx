# Typography

Two families, both from the operating system, nothing downloaded (L1): a sans for the interface and a
monospace for anything a developer would paste, read or copy (R01.2). The scale runs from 13 to 24 px and
has five steps; nothing on screen is smaller than 13 px.

## Roles

Pick a role, not a size. Each role maps to one size token and one weight.

## Rules

| Rule | Source |
|---|---|
| Running text is at most about 65 characters per line: `max-width: var(--measure)` on paragraphs and session messages. | prompt stage 1.5 (proposal token `--measure`) |
| Author lines in the session: name in Label weight, time in Metadata colour and size, on one line. | R02.1 |
| Code, file names, commands and identifiers are always monospace, also inline in a sentence. | R01.2 |
| No gradient text, no letter-spaced uppercase eyebrows, no coloured word inside a heading. | A01 |
| Headings are sentence case. Button labels are verb + object ("Book and pay", "Decline question"). | L3 |
| Minimum size 13 px; metadata is the only role that uses it. | L1 |
