# Skeleton

## 1. Purpose

Holds the shape of content while it loads.

## 2. When to use

Mentor list, bookings list on first load.

## 3. When not to use

Actions in progress (button loading state), loads under 300 ms (show nothing).

## 4. Anatomy

Block in `--muted`, no pulse animation.

## 5. Variants

Sized by `className` to match content.

<Canvas of={Stories.MentorRow} />

## 6. States

Static, `aria-hidden`; container gets `aria-busy`.

## 7. Behaviour and accessibility

Keyboard and screen reader behaviour from Radix / native HTML; focus 2 px `--ring`, offset 2 px; targets ≥ 24 px, controls 40 px. Portals take the theme from `<html>`.

## 8. Content

English UI, sentence case, concrete DevMentor data (dates, zł, names). Actions name the verb.

## 9. Responsive behaviour

Full width up to its max width; no horizontal scroll at 320 px.

## 10. API

`className`.

## 11. Code

```tsx
<Skeleton className="h-4 w-1/2" />
```

## 12. Do and don't

| Do | Don't |
|---|---|
| Use tokens only, no shadow (R01.1). | Hardcoded colours, `dark:` classes, entrance animations. |
