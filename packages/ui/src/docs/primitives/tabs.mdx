# Tabs

## 1. Purpose

Switches between views of the same object on one page.

## 2. When to use

Bookings: Upcoming / Past.

## 3. When not to use

Main navigation (R02.6 — open question for mentor nav), steps of a flow.

## 4. Anatomy

List with bottom `--border`, triggers 40 px, active = text `--foreground`, medium weight, 2 px `--primary` underline.

## 5. Variants

One (underline).

<Canvas of={Stories.Default} />

## 6. States

Default, hover, focus (2 px `--ring`), active, disabled. Arrow keys move between tabs.

## 7. Behaviour and accessibility

Keyboard and screen reader behaviour from Radix / native HTML; focus 2 px `--ring`, offset 2 px; targets ≥ 24 px, controls 40 px. Portals take the theme from `<html>`.

## 8. Content

English UI, sentence case, concrete DevMentor data (dates, zł, names). Actions name the verb.

## 9. Responsive behaviour

Full width up to its max width; no horizontal scroll at 320 px.

## 10. API

Radix Tabs props.

## 11. Code

```tsx
<Tabs defaultValue="upcoming">…</Tabs>
```

## 12. Do and don't

| Do | Don't |
|---|---|
| Use tokens only, no shadow (R01.1). | Hardcoded colours, `dark:` classes, entrance animations. |
