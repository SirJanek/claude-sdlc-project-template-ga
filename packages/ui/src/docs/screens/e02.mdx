# E02 Mentors become bookable

Backlog: E02 (#21), S01 (#28), S02 (#29), S03 (#30), S04 (#31). **No spec yet** — screens are PROPOSALS from the brief.

## Flow
1. Mentor writes headline and link to public work (R08, no scores — N02).
2. Mentor sets 25/50-minute prices (R11) and publishes slots (R01).
3. Mentor shares the link; optionally joins the catalogue (R09, D06).
4. Mentee opens the link or catalogue and sees price and earliest start before writing anything (R03, D05).
