# E03 Booking and payment

Backlog: E03 (#22), S01 (#32), T01 (#39), S02 (#34), S03 (#35), S04 (#36), S05 (#37), T01 (#40). **No spec yet** — screens are PROPOSALS.

## Flow
1. Mentee picks a slot (Slot list), writes the question (R05), sees the price summary and pays via Stripe (R04). Booking confirmed on payment.
2. Mentor sees the question; may decline → full refund (R12), confirmation dialog names the person.
3. Mentee may cancel/reschedule free until 12 h before (R10).
4. No-shows: mentor no-show → same-day refund (R06); mentee no-show → payment to mentor (R10).
5. After the first booking the mentor adds payout details (R07); weekly payouts (R14).
