# Usage and accessibility

## Keyboard and focus
- Everything works with Tab, Shift+Tab, Enter, Space, arrows; Esc closes dialogs and menus (WAI-ARIA APG).
- Focus is a 2 px `--ring` outline, offset 2 px, never removed (WCAG 2.4.7, 2.4.11; stage 2 decision 3).
- Dialogs trap focus and return it to the trigger; Confirm dialog focuses **Cancel** first (prompt, WAI-ARIA alertdialog).
- Targets at least 24 × 24 px (WCAG 2.5.8); controls 40 px (K1).

## Forms and messages
- Every control has a visible label via `FormField`; placeholder is an example (WCAG 3.3.2).
- Errors: text next to the field, linked with `aria-describedby`, `aria-invalid` (WCAG 3.3.1); after submit focus moves to the first error.
- Mark the minority with "Required"/"Optional" (decision 7).
- Errors that need action are never toasts (stage 0 decision 3).

## Colour
- Colour only for state (R01.3); accent only on the one main action (K2).
- Status always has text (WCAG 1.4.1). Text contrast ≥ 4.5 : 1, UI ≥ 3 : 1 (WCAG 1.4.3, 1.4.11) — see Foundations/Colour.
- Links in running text are underlined (stage 2 decision 4).

## Motion
- Only colour/border transitions in `--motion-fast`; none under `prefers-reduced-motion` (WCAG 2.3.3). No entrance animations, no skeleton pulse (PROPOSAL).

## Content
- English UI, sentence case; short and concrete (L3). See Content.

## Layout at 320, 768, 1440 px
- Single column at 320 px, no horizontal page scroll (WCAG 1.4.10). Content max width `max-w-content` (64rem, PROPOSAL); running text ≤ 65 ch (`--measure`).
- Session: question panel next to the thread from 768 px, above it on phones (R02.3).

## Product rules the interface enforces

| Rule | How the UI enforces it | Source |
|---|---|---|
| No scores on mentor pages | `MentorCard` has no rating prop | N02, R08 |
| Price and earliest start before writing | MentorCard, detail view above the fold | R03, D05 |
| 25 or 50 minutes only | `Slot.minutes: 25 \| 50` | R01 |
| Pay before session | Book and pay pattern: confirmed on payment | R04 |
| Free cancel until 12 h | PriceSummary states the deadline | R10 |
| Decline = full refund | Confirm dialog says so | R12 |
| Session visible only to the two | ended state text | E04-S01, R02 |

## Row actions and counts (agent test 1)
- Row action names its object: "Remove Anna Kowalska from favourites" (WCAG 2.4.6); chip "Remove filter Python".
- In progress: disabled + `aria-busy` + "Removing…"; failed: inline `role=alert` + "Try again", never a toast.
- Result count in `role=status` (WCAG 4.1.3).
- Field widths: `w-field-sm` / `w-field-md` (PROPOSAL).
- Phone check: Storybook viewport toolbar has Phone 320, Tablet 768, Desktop 1440.
