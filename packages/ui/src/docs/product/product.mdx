# Product components

Built only from primitives and tokens. Grouped by epic. Each story set shows data states: loading, empty, error, partial data, many items, long text. Imports from `@mentorhub/ui`.

| Component | Epic | Import | Use when | Don't use when |
|---|---|---|---|---|
| `MentorCard` | E02 | `import { MentorCard } from '@mentorhub/ui'` | A mentor in a list or catalogue: name, headline, technologies, price, earliest start, public work link | Never add ratings, stars or review counts (N02, A03) |
| `SlotList` | E02/E03 | `import { SlotList } from '@mentorhub/ui'` | Mentee picks a time; list grouped by day, one RadioGroup (stage 0 decision 4) | A calendar grid (rejected); fewer than 2 slots → still a list |
| `BookingRow` | E03 | `import { BookingRow } from '@mentorhub/ui'` | A booking in "My sessions" / mentor "Sessions" with a status badge (R01.3) | Status shown by colour only |
| `PriceSummary` | E03 | `import { PriceSummary } from '@mentorhub/ui'` | Right before paying (R04), states the 12 h rule (R10) | Showing commission to the mentee (PROPOSAL: commission is a payout rule, R11) |
| `SessionEntry` | E04 | `import { SessionEntry } from '@mentorhub/ui'` | One message in a session: author bold, time small grey, full width (R02.1, R02.2) | Bubbles, reactions, read receipts (A05, R02.5) |
| `SessionComposer` | E04 | `import { SessionComposer } from '@mentorhub/ui'` | Bottom of a live session; Enter sends, Shift+Enter new line (R02.2) | Outside a session (no DMs, A05) |
