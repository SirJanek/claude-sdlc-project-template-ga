## Decisions

- Name stays **MentorHub** (course prompt says "DevMentor"); packages `@mentorhub/*` — Jan.
- **pnpm workspaces** over npm workspaces (strict deps, monorepo standard) — Jan.
- **docker compose** Postgres 17 on port 5433 (no clash with the local Homebrew Postgres 16 on
  5432) over a native install — Jan.
- PR #1 merged first, then a fresh branch from `develop` — Jan.
- **TypeScript pinned to 6.x** (6.0.3): `pnpm add typescript` pulled 7.0, which typescript-eslint
  does not support yet. Rejected: dropping typescript-eslint. Revisit when it supports TS 7.
- **Entities with `defineEntity`, no decorators** — works in the Next.js (Turbopack) build without
  `reflect-metadata`. Rejected: decorators + SWC config.
- **Migrations via own script (`tsx src/scripts/migrate.ts`)** instead of `@mikro-orm/cli` — one
  config shared with the app, no CLI config discovery; the web runtime never loads the migrator.
- **Health check runs `select 1`** — MikroORM 7 connects lazily; `checkConnection()` said "down"
  on a healthy fresh process. Found only on the live server; unit test fake now mimics the real
  behaviour (lesson recorded).
- **Relative imports without `.js`** in workspace packages — Turbopack does not map `.js` to `.ts`
  (build failed); lesson recorded.
- **ORM packages also listed in `@mentorhub/app`** — with pnpm's strict layout the server externals
  must resolve from the app package.
- **Next.js telemetry disabled** in the Makefile — builds should not send data out.
- **`next-env.d.ts` ignored, generated by `next typegen`** in `typecheck`.
- **Nested `packages/*/CLAUDE.md` = `@AGENTS.md`** — Claude Code only reads AGENTS.md through a
  CLAUDE.md import; verified from the repo root (lesson recorded about launching in a subfolder).
- `Makefile` keeps `rollback` / `quarantine` stubs with "TODO: wire up", so the template's eval
  workflow still skips itself — intended until the safety-net step.
