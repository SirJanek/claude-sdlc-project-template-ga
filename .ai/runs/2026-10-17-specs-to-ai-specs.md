## Goal

Resolve the open question from the earlier runs: specs live only in `.ai/specs/`; the template
commands, skill and subagents write and read there; `docs/sdlc/spec.md` becomes a format template.

## Decisions

- **Specs: `.ai/specs/YYYY-MM-DD-slug.md`, merged through PRs, moved to `implemented/` after
  merge.** Why: course decision; one file per change instead of one global `spec.md`.
  Rejected: keeping `docs/sdlc/spec.md` as the working file (overwritten by every change, no
  history per feature).
- **The implementation plan is a `## Implementation plan` section appended to the same spec
  file** by `/sdlc-plan`; `docs/sdlc/plan.md` is its format template. Why: one artifact per
  change for review and verification, same shape as Open Mercato specs. Rejected: a separate
  `.ai/specs/...plan.md` (breaks the `YYYY-MM-DD-slug.md` naming rule) and a global
  `docs/sdlc/plan.md` (same problem as a global spec).
- **`docs/sdlc/intent.md` stays where it is** — product-level problem statement, not per change.
- **`docs/sdlc/LESSONS.md` stays for production incidents; agent learnings go to
  `.ai/lessons.md`** — recorded in AGENTS.md so the two are not mixed.
- **Protected path changed:** `.github/workflows/claude-review.yml` prompt now judges diffs
  against the spec in `.ai/specs/`; otherwise CI review would look for a file that is never
  filled. Separate commit, with the reason.
- Earlier run logs are history and were not edited; their open question is answered here.
